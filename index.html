Integrasi Google Sheets

Akses & Sync data dari device manapun

Spreadsheet Terhubung: Link Google Spreadsheet Aceng Production

Tempelkan Web App URL dari Google Apps Script untuk aktifkan otomatis simpan & unduh data.

Cara Menghubungkan Google Sheets (1 Menit):

  1. Buka Google Spreadsheet Anda via link di atas.
  2. Klik menu Ekstensi > Apps Script.
  3. Hapus semua kode di sana, lalu tempelkan Script khusus di bawah ini.
  4. Klik Terapkan (Deploy) > Penerapan Baru > Pilih jenis Web App.
  5. Setel Akses / Who has access ke Siapa Saja (Anyone).
  6. Klik Deploy, lalu salin **URL Web App** dan tempel di kolom atas!
